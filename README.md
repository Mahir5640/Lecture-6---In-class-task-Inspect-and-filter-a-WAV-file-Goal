# Lecture 6 – Inspect and Filter a WAV File

## Project Overview
This MATLAB exercise focuses on inspecting an audio recording, identifying unwanted noise, and applying a digital filter to improve the signal while preserving useful audio.

## Tools
- MATLAB Online
- Signal Processing Toolbox
- WAV audio file (MATLAB Handel example)

## Method
1. Loaded the audio using `audioread`.
2. Checked the sample rate, duration, and channels.
3. Inspected the waveform and spectrogram.
4. Applied a Butterworth band-stop filter with a 49–51 Hz stop band, targeting possible 50 Hz electrical hum.
5. Used `filtfilt` for zero-phase offline filtering.
6. Compared original and filtered audio using plots and playback at the same gain.

## Filter Settings
- Filter: Butterworth band-stop
- Design order: 2 (resulting band-stop order: 4)
- Stop band: 49–51 Hz
- Target interference: 50 Hz electrical hum

## Results and Discussion
The filter is designed to attenuate frequencies around 50 Hz while preserving most frequencies outside the stop band.

Whether the recording improved must be confirmed from the original and filtered spectrograms and listening comparison. The Handel example may not contain a noticeable 50 Hz hum, so attenuation of an existing hum cannot be assumed.

## Conclusion
This exercise demonstrates how to inspect WAV audio and apply a narrow band-stop filter. A narrow stop band limits changes to nearby useful audio, although any useful content around 50 Hz may also be reduced.
